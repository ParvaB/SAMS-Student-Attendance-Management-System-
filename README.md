# SAMS-Student-Attendance-Management-System-
Student Attendance Management System (SAMS) is a responsive SaaS web app for B.Tech CS Sem V built with React and Tailwind CSS. It features 5 role modules (Student, Faculty, Coordinator, HOD, Admin), shortfall recovery math, 3-tap attendance marking, 48h BVA correction windows, automated guardian alerts, and a SHA-256 immutable audit ledger.
